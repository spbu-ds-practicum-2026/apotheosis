# Техническое решение проекта «Название проекта»

## Введение
- **Цель проекта:**  
  «Лента картинок» - учебный проект, реализующий прототип распределенной платформы для просмотра картинок, которые предположительно интересны пользователю, в формате бесконечной ленты. Проект демонстрирует ключевые принципы построения отказоустойчивых и масштабируемых распределённых приложений.

- **Основания для разработки:**

## Функциональные требования
Система должна предоставлять следующие функции:
1. Авторизация и аутентификация пользователя.
2. Генерация ленты.
3. Бесконечный скроллинг.
4. Взаимодействие с контентом - пользователь должен иметь возможность отмечать понравившиеся изображения (например, ставить «лайк»).
5. Система должна учитывать взаимодействия пользователя (просмотры, лайки) для корректировки выдачи последующих картинок.

---

## Нефункциональные требования
1. Отказоустойчивость - выход из строя одного или нескольких узлов (частичный отказ) не должен приводить к полной неработоспособности приложения. Пользователь должен продолжать получать картинки (возможно, с деградацией качества рекомендаций).
2. Доступность - система должна отдавать приоритет доступности над строгой консистентностью (задержка в отображении лайка предпочтительнее недоступности ленты).
3. Время ответа на запрос новой порции картинок не должно превышать приемлемых значений, чтобы обеспечить плавность бесконечной прокрутки.
4. Использование механизмов кэширования (горячих данных) для часто запрашиваемых картинок и распределенного хранения статики.
5. Серверная часть разрабатывается с применением очередей сообщений и распределенных БД.
